# Muster releases

Signed Android builds of Muster, a weekend board that shows when
everyone in a group is free (no sign-up). Installed copies update
themselves from here. In a browser: https://muster.teloone.au

**[Download Muster 1.4.1](https://raw.githubusercontent.com/matisseduffield/muster-releases/main/Muster.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 1.4.1

- Delete on an event has moved to the bottom of its card, away from the title
